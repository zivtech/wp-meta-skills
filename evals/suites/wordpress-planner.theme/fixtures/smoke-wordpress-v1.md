# Smoke Fixture: wordpress-planner.theme

Scenario: Plan a WordPress block theme for an editorial site that needs a
home page, article page, archive, navigation, and newsletter callout. The
existing WordPress content model is stable. The design direction is supplied as
approved written requirements, not an external application repository.

Plan the theme as a WordPress-native block theme. Define `theme.json` tokens,
templates, template parts, patterns, responsive and accessibility behavior,
editor/frontend verification, and a clear executor/critic handoff. Do not
invent a design-system repository, portable application architecture, or
external-asset licensing issue that is absent from this fixture.

The candidate output must demonstrate the contract of `wordpress-planner.theme`
without claiming unsupported benchmark results. It must cite assumptions, avoid
unsafe production actions, and name the downstream planner/executor/critic
handoff when applicable.
